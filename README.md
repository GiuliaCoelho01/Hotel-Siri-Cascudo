# Hotel-Siri-Cascudo
Como atividade acadêmica, desenvolvemos em Kotlin o sistema do Hotel Siri Cascudo. Ele conta com login seguro, gestão de 20 quartos, cadastro de 15 hóspedes, aluguel de auditórios para eventos, comparação de manutenção e postos de combustível, consolidando dados e receitas em relatórios operacionais.
